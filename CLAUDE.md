# Pravidlá pre Claude Code v cloude
- Komunikuj vždy po slovensky. Miro je začiatočník: vysvetľuj jednoducho, bez žargónu.
- Pri väčších úlohách najprv navrhni plán a počkaj na Mirov súhlas.
- data.json NIKDY nemeň (ani skriptom, ani príkazom). Hlavná kópia dát je na Mirovom PC. data.json smieš len čítať. Návrhy obsahu (popisy a pod.) zapisuj do samostatného súboru v priečinku navrhy/.
- sitemap-lastmod.json nemeň — spravuje ho GitHub Actions.
- Nikdy nepushuj do main. Každá zmena = vlastná vetva + pull request. Merge robí len Miro.
- Web má 2 repozitáre: sport-linky (slovenský, sportlinky.sk) a sportlinking (anglický, sportlinking.com) s rovnakou štruktúrou. Ak sa zmena týka oboch webov, povedz to Mirovi — druhý repozitár sa robí samostatnou úlohou.
- Na konci vždy napíš jednoduché zhrnutie: ktoré súbory si zmenil, prečo, a čo má Miro skontrolovať.
